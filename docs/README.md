# Documentation

This directory describes the behavior implemented by Solar Forge Boards. Start with the user guide
for the browser experience or the API reference when building a client.

- [Local LLM and coding-agent guide](../AGENTS.md): repository rules, architecture invariants,
  safety constraints, commands, and completion checklist for agents editing the project.
- [User guide](user-guide.md): projects, stories, tags, filtering, board views, movement, and
  deletion.
- [JSON API](api.md): endpoints, payloads, validation, lifecycle rules, activity, and errors.
- [Architecture](architecture.md): layers, data model, transaction boundaries, and browser-local
  behavior.
- [Development and operations](development.md): local and Docker setup, configuration, migrations,
  checks, and data safety.
- [Solar Forge integration](solar-forge.md): recommended agent tools, context strategy, and
  production prerequisites.
- [Recommended next steps](roadmap.md): prioritized product, security, integration, and operations
  roadmap.

The root [README](../README.md) contains the shortest path to a running application.
